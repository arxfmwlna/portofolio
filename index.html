02 / Kenapa ini dikerjakan

Satu lembar kerja menyimpan terlalu banyak keputusan

Seluruh pemantauan program awalnya bertumpu pada satu berkas kerja Excel: memproses 379.503 baris data penjangkauan, 24.578 rumus rekapitulasi, dan 39 pivot table dengan satu tombol Refresh. Semuanya tampak berjalan wajar, sampai terjadi perubahan definisi indikator di lapangan.

Risiko 01

Baris subtotal ikut terakumulasi bersama data input petugas lapangan, menyebabkan angka capaian terhitung ganda.

Risiko 02

Indikator yang bersifat kumulatif semesteran dijumlahkan ulang setiap bulan, membuat pelaporan capaian membengkak hingga 3,5 kali lipat.

Risiko 03

Data hasil tes medis klien yang sensitif terbuka langsung di lembar kerja tanpa pembatasan hak akses.

Angka struktur bersumber dari audit berkas Dashboard Capaian YPI, diperiksa 12 November 2026.

07 / Cara kerja

Logika pemantauan dirumuskan dari domain Monev, AI mempercepat implementasi kode

AI tidak memahami dinamika penjangkauan lapangan maupun batasan Petunjuk Teknis. Seluruh aturan bisnis, struktur basis data, dan skenario validasi dirumuskan dari keahlian Monev saya, sementara AI dimanfaatkan sebagai akselerator teknis untuk menulis sintaksis kode dan mempercepat penyusunan pengujian otomatis.

Pemodelan analitik di Excel

57 sheet, 136 kolom bantu, dan 24.578 rumus rekapitulasi dirancang langsung dari pengalaman lapangan untuk memvalidasi alur kalkulasi sebelum proses migrasi.

Rantai dampak Theory of Change

Logika pemantauan diturunkan langsung dari alur intervensi program: penjangkauan populasi kunci, tindak lanjut rujukan ke layanan kesehatan, hingga retensi pengobatan.

AI sebagai akselerator teknis

AI dimanfaatkan secara terarah pada tahap pengembangan web untuk mempercepat penulisan komponen Next.js, pengetikan TypeScript, dan kerangka pengujian.

Verifikasi 1.003 uji otomatis

Setiap aturan teknis bernomor divalidasi oleh rangkaian uji otomatis (unit dan integration test) untuk memastikan kode berjalan persis sesuai mandat Juknis.

Tata kelola dan kendali penuh

Mulai dari arsitektur sistem, isolasi hak akses pengguna, pembersihan data sensitif, hingga pengoperasian server fisik berada sepenuhnya di bawah kendali saya.

C / Operasi

Server pribadi

Aplikasi dan basis data beroperasi penuh di server fisik lokal mandiri. Akses pengguna dari luar diamankan melalui Cloudflare Tunnel terenkripsi tanpa mengekspos port terbuka ke jaringan publik.

  • Menggunakan perangkat server fisik Lenovo ThinkCentre M710s dengan sistem operasi Windows 10.
  • Process manager (PM2) menjaga ketersediaan layanan Next.js tetap aktif dan terpantau.
  • Basis data relasional PostgreSQL beroperasi di dalam kontainer Docker pada server lokal.
  • Nol port masuk publik terbuka, meminimalkan risiko serangan dan pemindaian jaringan dari luar.
