02 / Kenapa ini dikerjakan

Satu lembar kerja menyimpan terlalu banyak keputusan

Dulu satu berkas Excel menampung 379.503 baris data penjangkauan, 24.578 rumus rekap, 39 pivot table, dan satu tombol Refresh. Semuanya tampak beres, sampai definisinya bergeser.

Risiko 01

Baris total ikut terhitung bersama baris petugas, sehingga angka capaian berlipat ganda.

Risiko 02

Nilai bulanan yang bersifat kumulatif dijumlahkan ulang, membuat laporan bengkak hingga 3,5 kali.

Risiko 03

Status tes kesehatan yang sensitif terpapar sebagai teks terbuka di layar kerja.

Angka struktur bersumber dari audit berkas Dashboard Capaian YPI, diperiksa 12 November 2026.

C / Operasi

Server pribadi

Aplikasi dan basis data beroperasi penuh di server lokal mandiri. Akses pengguna dari luar diamankan melalui Cloudflare Tunnel tanpa perlu membuka port masuk ke internet publik.

  • Menggunakan perangkat server fisik M710s dengan sistem operasi Windows 10.
  • PM2 menjaga proses aplikasi Next.js tetap aktif dan terpantau.
  • PostgreSQL beroperasi di dalam kontainer Docker pada server lokal.
  • Nol port publik terbuka, meminimalkan risiko serangan dari jaringan luar.
